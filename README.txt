BASIC ENCRYPTION & DECRYPTION

Project 2 - Cyber Security Internship

Description:
This project implements basic encryption and decryption using the Caesar Cipher technique.

Objective:
To convert readable text into an encrypted form and decrypt it back to the original text.

Features:
- Encrypts user-provided text
- Uses a user-defined shift key
- Decrypts the encrypted text
- Displays both encrypted and decrypted text
- Preserves spaces, numbers, and special characters

Technology Used:
Python

Encryption Method:
Caesar Cipher

Example:
Input Text: everyone
Shift Key: 3
Encrypted Text: hyhubrqh
Decrypted Text: everyone

How to Run:
1. Open the Python file.
2. Enter the text.
3. Enter the shift key.
4. View the encrypted and decrypted output.

Project Domain:
Cyber Security
