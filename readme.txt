PHISHING AWARENESS ANALYSIS

Project: Cyber Security Internship - Project 3
Organization: DecodeLabs
Technology: Python

OBJECTIVE:
To analyze sample emails or messages and identify possible phishing attempts.

FEATURES:
- Identifies suspicious keywords
- Detects suspicious links
- Lists red flags found in messages
- Explains why a message may be unsafe

HOW IT WORKS:
1. User enters an email or message.
2. The program checks for suspicious keywords and links.
3. Red flags are displayed if detected.
4. The program explains why the message may be unsafe.

SAMPLE PHISHING INDICATORS:
- Urgent messages
- Prize or winner claims
- Password or account verification requests
- Suspicious links
- Limited-time offers

TECHNOLOGY USED:
Python

KEY LEARNING:
This project helped me understand phishing indicators, threat analysis,
and basic cybersecurity awareness.
